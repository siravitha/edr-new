# ข้อมูลหลักในตั้งค่าระบบ

เมนูย่อยมีจัดการผู้ใช้งาน รหัสคุมเอกสาร แผนก/ฝ่าย ข้อมูลโรงพยาบาล และผู้ค้ากับโรงพยาบาล

ทะเบียนสี่ประเภทเพิ่ม แก้ไข ระงับ คืนสถานะ และยกเลิกได้โดยมุมมองผู้ดูแลระบบจำลอง การยกเลิกต้องมีเหตุผล เป็นสถานะสุดท้ายและเก็บแถวเดิม รหัสไม่ถูกนำกลับมาใช้ซ้ำ แก้ไขแล้วรหัสคงเดิม เมื่อครบ 9999 ต้องกำหนดนโยบายขยายรหัสก่อน ไม่วนกลับ 0001

| ประเภท | ตัวอย่าง |
|---|---|
| ผู้ใช้ | USR-0001 |
| รหัสคุมเอกสาร | DOC-0001 |
| แผนก/ฝ่าย | DEP-0001 |
| ผู้ค้า | VEN-0001 |

รหัสทะเบียนใช้ตัวอักษรอังกฤษสามตัวและตัวเลขสี่หลัก อักษรนำหน้าตระกูลเอกสารเป็นอีกช่องหนึ่ง เช่น PR หรือ PO จำกัดอังกฤษตัวใหญ่ 1–3 ตัว ไม่ใช่การออกเลขเอกสารราชการจริงในรุ่นนี้

ข้อมูลโรงพยาบาลเป็นชุดเดียว ไม่มีเลขรันหรือสถานะระงับ/ยกเลิก ใส่ชื่อ รหัสโรงพยาบาลทั่วไป ที่อยู่ ช่องทางติดต่อ และรูป PNG/JPEG/WebP ไม่เกิน 500KB พร้อมตัวอย่างหัวรายงาน การส่งออก CSV เดิมยังเป็นข้อมูลตาราง ไม่ใช่ PDF ที่มีหัวกระดาษ

ข้อมูลเก็บใน IndexedDB ของต้นแบบ ไม่ใช่ฐานกลางโรงพยาบาล รูปและทะเบียนต่างที่อยู่เว็บจะไม่ใช้ร่วมกัน ไม่ส่งอีเมลหรือสร้างบัญชี Provider ID ตำแหน่งแยกจากบทบาทและอำนาจอนุมัติ ผู้ใช้ใหม่ยังรอยืนยันตัวตน

ระบบจริงต้องออกเลขด้วยตัวนับและ unique constraint ในธุรกรรมฝั่งเซิร์ฟเวอร์ ตรวจสิทธิ์จากข้อมูลปัจจุบัน และเก็บ audit ผู้ทำรายการ/เวลา/เหตุผลให้ตรวจย้อนกลับได้ การเคลียร์ข้อมูลเบราว์เซอร์ของต้นแบบไม่ใช่กระบวนการเก็บทะเบียนถาวรตามระเบียบ
