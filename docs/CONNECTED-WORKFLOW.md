# สายงานเชื่อมโยง 5 ฝ่าย — ต้นแบบ

สร้าง PR ได้จากรายการแผนสถานะ SENT เท่านั้น โดยตรึงฉบับแผน แหล่งเงิน ปี จำนวน และวงเงิน หนึ่งรายการแผนมี PR ที่ยังไม่ยกเลิกได้หนึ่งฉบับ ยังไม่รองรับแบ่งรายการเดียวเป็นหลาย PR การเปลี่ยนฉบับแผนจะหยุดการเสนอ/เห็นชอบ/ทำสัญญาจนทวนสอบใหม่

สายงาน: ร่าง PR → เสนอ → บันทึกผลเห็นชอบ → TOR/ราคากลาง → บันทึกผลวิธีจัดหา → สัญญาที่ลงนามและผูกพัน → ตรวจรับรายงวด → ตั้งเบิก → ตรวจการเงิน → อนุมัติ → บันทึกหลักฐานจ่าย การตรวจเอกสารบัญชีทำหลังตรวจรับได้โดยไม่ต้องรอจ่ายเงิน

ยอดเงินในตรรกะเก็บเป็นสตางค์จำนวนเต็ม แยกวงเงินแผน ผูกพัน ตรวจรับ ตั้งเบิก และจ่าย ไม่รวมแหล่งเงิน การผูกพันเกิดตอนสัญญาเท่านั้น ราคาสัญญาต้องไม่เกินรายการแผน แผนจ่ายรายปีรวมต้องตรงสัญญา ทั้งนี้ยังไม่ใช่การรับรองอำนาจผูกพันข้ามปีหรือยอดงบคงเหลือจากระบบกลาง

ตรวจรับได้บางส่วน ไม่เกินจำนวนสัญญา ครุภัณฑ์รายเครื่องส่งเข้า intake ที่ผ่านตรวจรับแล้วโดยไม่ออกเลขอัตโนมัติ ผู้ใช้ไปออกเลขในเมนูเดิมได้ ไม่ต้องรอจ่ายเงิน ใช้คู่รหัสที่ยืนยันแล้ว 7110-010 เท่านั้น ยังไม่ใช่ระบบมติคณะกรรมการหรือการลงนามอิเล็กทรอนิกส์

ตั้งเบิกหนึ่งคำขอต่องวดตรวจรับ ป้องกันใบแจ้งหนี้ซ้ำต่อผู้ค้า ส่งคืนและส่งใหม่โดยเก็บประวัติ ไม่ย้อนหรือเปิดสัญญา ผู้จัดทำเป็นพัสดุ ผู้ตรวจและบันทึกหลักฐานจ่ายเป็นการเงิน ผู้อนุมัติเป็นผู้บริหารจำลองซึ่งแยกจากผู้จัดทำและผู้ตรวจ ไม่ใช่การกำหนดอำนาจจริงให้บุคคลใด

ขั้นยืนยันต้องมี PDF ที่ตรวจรูปแบบพื้นฐาน SHA-256 เลขอ้างอิง และยืนยันตรวจต้นฉบับหมึก ไฟล์กับสถานะและ Log บันทึกในธุรกรรม IndexedDB เดียวกัน ยืนยันไม่ได้เมื่อออฟไลน์ ป้องกันการเขียนข้อมูลจากหน้าจอรุ่นเก่าและแท็บที่ไม่มีสิทธิ์เขียนด้วยกลไกเดิม ไม่มีการสแกนมัลแวร์หรือรับรองความแท้ของลายเซ็น

นิติกรรับข้อหารือจากรายการและตอบพร้อม PDF ได้ ไม่บังคับส่งทุกสัญญา หากส่งแล้วเรื่องยังเปิดอยู่จะไม่ให้บันทึกสัญญาจนตอบความเห็น ตามข้อกำหนดของต้นแบบ มิใช่ข้อบังคับทางกฎหมายทั่วไป

บัญชีรับรองความครบถ้วนเอกสารและเสนอคู่บัญชีได้ แต่ยังไม่ลงสมุดรายวัน ไม่รับรองผังบัญชีหรือค่าเสื่อม ไม่เปลี่ยนยอดสินทรัพย์สุทธิที่รอรับรอง ยังไม่มีบัญชีแยกประเภท ปิดงวด และส่ง New GFMIS Thai

เมนูทั้ง 5 ฝ่ายประกาศสถานะ ทดลองได้/บางส่วน/ยังไม่พัฒนา ตาม lib/workspace-menu.ts การมีเมนูหรือสคีมาไม่ถือว่าเสร็จครบกระบวนการ หัวข้อที่ค้างจะแสดงขอบเขตงาน ไม่สร้างข้อมูลสำเร็จปลอม

ทั้งหมดเป็นต้นแบบในเบราว์เซอร์ ไม่มีการประกาศหรือแข่งขันใน e-GP ไม่มีการโอนเงิน ไม่มีระบบกลางหรือ Provider ID จริง ไม่ควรใส่ข้อมูลราชการลับหรือข้อมูลผู้ป่วย
