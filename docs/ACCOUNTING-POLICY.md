# แบบจำลองวงจรและนโยบายบัญชีระยะสอง

แค็ตตาล็อก 15 ขั้นเป็นภาพการทำงานร่วมกันของยุทธศาสตร์ พัสดุ การเงิน บัญชี คลัง และผู้มีอำนาจ ไม่ใช่ข้อบังคับว่าทุกกรณีต้องผ่านทุกขั้นเหมือนกัน รองรับประเภทจัดซื้อ บริการ ซ่อม เช่า ก่อสร้าง และบริจาคในแค็ตตาล็อก กับแหล่งเงินงบประจำปี เงินบำรุง และเงินบริจาค การรับบริจาคที่ไม่มีเงินจ่ายต้องใช้ทางรับทรัพย์สินและนโยบายรับรู้แยก ไม่สร้างสัญญาจ่ายเงินปลอม

แบบจำลองหนึ่ง state แทนหนึ่งกรณี/สัญญาและหนึ่งวงเงิน `allocatedSatang` เป็นงบจัดสรร `committedSatang` เป็นภาระผูกพันที่ยังไม่จ่าย และ `paidSatang` เป็นจ่ายจริง งบพร้อมใช้ = จัดสรร − ผูกพันคงเหลือ − จ่ายจริง ลงนามแล้วจึงผูกพัน จ่ายเงินแล้วลดผูกพันพร้อมเพิ่มจ่ายจริงในคำสั่งเดียว ยกเลิกคืนเฉพาะผูกพันที่เหลือ ไม่คืนเงินที่จ่ายไปแล้ว การแก้สัญญา โอนงบ คืนเงิน และการผูกพันหลายสัญญายังต้องพัฒนาต่างหาก

คำสั่งมีโรงพยาบาล ผู้ใช้ บทบาท และเลขคำสั่งเดิมที่ส่งซ้ำได้ เก็บลายนิ้วมือสาธิตพร้อมข้อความ canonical เต็มเพื่อปฏิเสธการใช้เลขคำสั่งเดิมกับเนื้อหาอื่น ลายนิ้วมือนี้ไม่ใช่ cryptographic hash สำหรับหลักฐานตรวจสอบ ตัว reducer เป็น immutable และเปลี่ยนยอด/บันทึกคำสั่งพร้อมกันในหน่วยความจำ ไม่รับประกันธุรกรรมพร้อมกันระหว่างหลายเครื่อง เมื่อนำไป backend ต้องล็อกแถววงเงิน ตรวจ version และ unique key คำสั่งภายในธุรกรรมฐานข้อมูลเดียวกัน พร้อมสร้าง audit จากตัวตนที่เซิร์ฟเวอร์ตรวจแล้ว ห้ามเชื่อบทบาทจาก browser

เอกสารทุกคำสั่งต้องมีธงว่าลงนามหมึกจริงและตรวจเทียบแล้ว ธงในต้นแบบไม่ได้ยืนยันเอกสารจริง ระบบจริงต้องผูกเลขเอกสาร รุ่น ไฟล์สแกน hash ผู้ตรวจ วันตรวจ และที่เก็บต้นฉบับ พร้อมควบคุมสิทธิ์ผู้ตรวจ

ค่าเสื่อมใช้เส้นตรงสะสมเป็นสตางค์ โดยรับต้นทุน มูลค่าคงเหลือ อายุเดือน วันเริ่ม และจำนวนเดือนที่ผ่านมาตามนโยบายที่อนุมัติ ไม่มีอัตราหรืออายุใช้งานเริ่มต้นที่อ้างว่าเป็นเกณฑ์ราชการ ใช้จำนวนเต็ม BigInt ภายในก่อนแปลงผลกลับ จึงไม่สูญเสียเศษในเดือนสุดท้าย `elapsedMonths` ต้องคำนวณจากวันพร้อมใช้และหลักการเริ่มคิด/ปัดเดือนของนโยบายที่รับรองก่อน ไม่สมมติว่าผ่านเดือนปฏิทินเท่ากับต้องคิดค่าเสื่อมหนึ่งเดือน

ค่าเสื่อมครบอายุไม่เปลี่ยนเป็นจำหน่าย: ต้องตรวจสภาพจริง ผู้มีอำนาจอนุมัติแยกบุคคล และมีหลักฐานดำเนินการจำหน่าย ระบบยังไม่ได้สร้างรายการกลับบัญชีหรือหนังสืออนุมัติที่มีผลจริง และยังไม่ทราบชื่อหรือสัญญาข้อมูลของสองระบบที่จะเชื่อม ห้ามใช้ตัวอย่างนี้แทนอำนาจอนุมัติหรือข้อวินิจฉัยทางกฎหมาย
